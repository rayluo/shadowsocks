Useful Tools
===========

autoban.py
----------

Automatically ban IPs that try to brute force crack the server.

See https://github.com/shadowsocks/shadowsocks/wiki/Ban-Brute-Force-Crackers


bootstrap.py
------------

If you don't use shadowsocks server often,
you end up relearning how to configure it everytime.
This script guides you through the process by asking questions in the console.

Usage: python bootstrap.py
